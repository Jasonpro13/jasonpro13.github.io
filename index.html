🎥 What This Tool Does

AI-Video-Effects-API is a collection of more than 160 video effect presets, visual effects and camera-movement recipes. Instead of building complicated editing timelines by hand, you choose a preset by name and the application handles the heavy lifting for you.

The project includes three helpful pieces: a full endpoint guide so you can see every effect that exists, a side-by-side comparison of similar effects so you can pick the right one, and runnable examples you can follow step by step. The examples are written for everyday tools such as curl, Python and JavaScript, and each one is short enough to read in a minute.

Because every effect has a clear name and a matching example, you never have to guess which setting produces which look. You find the look you want, copy the matching recipe, and move on.

📚 Inside the Endpoint Guide

The guide lists every effect in plain language next to its technical name. For each entry you get the effect family, a short description of the result, the parameters you can change, and a ready-to-run example.

A comparison table groups look-alike effects together so you can see the difference at a glance. For instance, a slow orbit and a dolly push both move toward the subject, but one circles it while the other travels straight in. Seeing them side by side makes the choice obvious.

Runnable examples are provided for curl, Python and JavaScript. You can copy an example, swap in your own file name, and see the result without writing anything from scratch.
