# Queer Nerds York

A single-page site for the Queer Nerds York monthly social.

## Update the next meetup

Open `index.html` in GitHub and select the pencil icon. Search for “Update the three values below”. Edit the text between the three pairs of `<dd>` and `</dd>` tags for the date, time and venue, then commit the change to `main`. GitHub Pages publishes the update automatically.

To change the Reddit or Discord destinations, edit the two links in the “Meetup updates” section of the same file.

## Set up GitHub Pages

Create a public repository named `queer-nerds-york` and add these files to the root of its `main` branch. In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. Use the URL GitHub displays in that section for the poster.
